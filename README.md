# Anonymizer 去識別化工具

把文字或檔案中的路徑、使用者名稱、IP、Email、電話、帳號密碼、中文名詞（人名、組織、地名等）換成隨機代號，再貼給 AI。
單一 `index.html`，全部在瀏覽器本機處理，不會上傳任何資料，不需安裝、不需網路（選用的「中文名詞」第一次使用時需要下載模型）。

## 使用方式

1. 用瀏覽器開啟 `index.html`。
2. 在「① 原始文字」貼上內容，「② 去識別化結果」會即時產生，按「複製」後貼給 AI。想先試用可按「範例」，會隨機顯示三種範例之一：程式錯誤訊息（路徑、使用者、IP、帳密、Token、UUID）、網路設備設定檔（設備密碼、SNMP、MAC、私鑰）、會議紀錄（電話、Email、帳密，以及需勾選「中文名詞」才會遮蔽的人名與公司），不會連續出現同一種。
3. 取得 AI 回覆後，到「③ 還原 AI 回覆」貼上，會自動把代號換回原始內容（不需按鈕），按「複製」即可取用。

## 功能

- **遮蔽項目**（可個別開關）
  - Windows 路徑（`C:\...`、`C:/...`、`\\主機\分享`；程式碼或 JSON 裡跳脫成 `C:\\Users\\...` 的路徑也可以，分隔符會原樣保留）
  - Linux / macOS 路徑（`/home/...`、`~/...`）
  - IPv4 / IPv6 / MAC 位址（可保留 127.0.0.1、::1 等本機位址）
  - Email
  - 台灣電話號碼（預設開啟）
    - 手機：標準寫法 `0911-123456`；也能偵測 `0911123456`、`0911-123-456`、`0911 123 456`、`+886-911-123456`、`+886911123456`
    - 市話：區碼後要有分隔，例如 `02-2345-6789`、`(02)2345-6789`、`02 2345 6789`、`037-123456`、`0800-123-456`、`+886-2-2345-6789`；可帶分機（`#123`、`轉123`、`分機123`、`ext 123`），分機會一起遮蔽
    - 前後緊接英數字或 `-` 的數字不會偵測（例如 `SN-02-2345-6789`、`09111234567`）
  - 中文名詞（選用，預設關閉）：用 AI 模型辨識專有名詞，不細分類型，辨識到就遮蔽；同一個名詞會像關鍵字一樣遮蔽所有出現的位置（含 ① 與所有批次檔案），代號前綴為 `NAME`
    - 範圍：人名、組織、國家城市、地點、建築設施、族群團體、事件、產品、作品、法律；不含語言（例如「中文」）與日期、時間、數字、金額
    - 模型：中研院 CKIP 的 `bert-base-chinese-ner`（Hugging Face 上的 ONNX 版 `Xenova/bert-base-chinese-ner`），透過 [Transformers.js](https://github.com/huggingface/transformers.js) 在瀏覽器內執行
    - 勾選後才會下載：模型約 98 MB＋ONNX Runtime 約 26 MB，下載後存在瀏覽器快取，之後開頁會自動從快取載入；文字本身不會上傳
    - 用 `file://` 直接開啟時瀏覽器無法快取模型，每次開頁都要按「下載模型」重新下載；建議用 GitHub Pages 或本機伺服器開啟
    - 在背景執行緒（Web Worker）執行，頁面不會卡住；背景執行緒無法使用時會自動改在主執行緒執行（狀態會顯示「主執行緒模式」，辨識時頁面可能短暫停頓）
    - 只處理含中文字的行，結果逐行快取，修改文字時只重跑有變動的行
    - 辨識完成前「複製」與檔案下載按鈕會暫停，避免漏遮；狀態顯示在選項下方與 ② 標題列
    - 信心分數低於 0.5、只有一個字、超過 30 個字或不含中文字的結果會略過
    - 選項下方可「刪除模型」釋放瀏覽器空間，之後要用需重新下載
  - 帳號、密碼、Token（`password=...`、`Bearer ...`、`user:pass@host` 等）
  - 私鑰：`-----BEGIN ... PRIVATE KEY-----` 到 `-----END ... PRIVATE KEY-----` 整段換成一個代號（RSA、EC、OpenSSH、加密私鑰皆可）；缺少結尾行的截斷內容也會遮蔽後續的標頭與 Base64 行
  - 憑證：`-----BEGIN CERTIFICATE-----` 到 `-----END CERTIFICATE-----`（含 `CERTIFICATE REQUEST`）整段換成一個代號，可省下大量 token；缺少結尾行的截斷內容也會遮蔽後續的 Base64 行
  - UUID / GUID：`8-4-4-4-12` 格式的十六進位字串（可含大括號，不分大小寫），例如 Fortinet 的 `set uuid`；不完整的片段不會被偵測
  - 設備設定檔密碼（Cisco / Arista、Juniper、Fortinet）：只遮蔽「值」，保留關鍵字與引號
    - Cisco / Arista：`enable secret/password`、`username ... secret/password`、`snmp-server community`、`tacacs-server key`、`radius-server key`、server 區塊內的 `key 7 ...`、`ntp authentication-key`、`message-digest-key`、`crypto isakmp key`、`wpa-psk`、`ppp chap/pap password`、帶類型編號的 `password 7 ...`、`secret 5 ...`、`key-string 7 ...`，以及 `$1$` `$5$` `$6$` `$8$` `$9$` 等雜湊字串；Cisco 點分 MAC（`0011.2233.4455`）併入 IP / MAC 項目
    - Juniper：`encrypted-password`、`authentication-key`、`secret`、`ascii-text`、SNMP `community`（含 `authorization` 區塊）、`user NAME {`
    - Fortinet：`set ... ENC ...`、`set password/passwd/psksecret ...`
  - 其他位置出現的使用者名稱
  - 自訂關鍵字（逗號或換行分隔，例如公司名、主機名稱）；比對不分大小寫。英數關鍵字一律以整段比對：關鍵字開頭或結尾是英數字者，前後不能緊接英文、數字、底線，也不能緊接 `-` 再接英數字（視為同一段的延續）。例如 `TW` 會遮 `(TW)`、`在TW的`、`TW.exe`，但不會遮 `between`、`TW-01`；需要遮 `TW-01` 請另外加入
  - 快速遮蔽／取消遮蔽：在 ①、② 或檔案預覽中用滑鼠選取文字，旁邊會出現按鈕
    - 選到沒遮蔽的文字 →「遮蔽」：加入關鍵字，所有出現的位置都會遮蔽；若這段文字在白名單中會一併移除
    - 選到已遮蔽的內容（代號或 ① 中的標示文字）→「取消遮蔽」：加入白名單，一次可取消多項
    - 按住 Alt（Mac 為 Option）選取，放開滑鼠就直接執行，不顯示按鈕；按 Esc 或點別處可關閉按鈕
    - 限制：至少 2 個字；含換行、逗號或分號的內容無法當作關鍵字（請改用自訂 Regex）；英數關鍵字需整段相符，只選到單字的一部分不會遮蔽（會提示）
  - 白名單（不遮蔽）：每行一個，不分大小寫；命中的內容一律保留原文，優先於所有遮蔽規則（含關鍵字與中文名詞）
    - 快速加入：在 ①、② 或檔案預覽中按住 Ctrl（Mac 為 Command）點擊已遮蔽的文字、選取後按「取消遮蔽」，或在對照表按「解除」
    - 白名單裡包含較短的關鍵字或名詞時，白名單文字內的部分也不會被遮（例如白名單有「王志明」，就不會變成「王[NAME-xxx]」）
    - 多行內容（私鑰、憑證區塊）無法加入白名單
  - 自訂 Regex（另一個輸入框，每行一條；可寫成 `/樣式/旗標`，旗標可用 `i`、`m`、`s`、`u`）：代號對應實際比對到的文字，例如 `\d{5}L\d{3}` 會讓 `12345L678` 與 `99999L000` 各得一個代號。與關鍵字相同，以整段比對（例如 `911111A1112`、`28961708-9d58-...` 這類 uuid 不會只被遮掉其中一段）
    - 語法錯誤、會比對到空字串的 Regex 會顯示錯誤並略過
    - 巢狀量詞（例如 `(a+)+`）會顯示效能風險提示
    - 每條 Regex 會先在背景執行緒（Web Worker）對目前的文字與批次檔案試跑，超過 0.5 秒就中止並略過，頁面不會卡住；試跑完成前該條暫不套用。瀏覽器不支援背景執行緒時改為只做靜態檢查，有風險提示的 Regex 不套用
- **路徑取代方式**
  - 保留結構：逐層目錄各換成代號
  - 只保留檔名：前面的目錄整段取代
  - 整段路徑取代
- **隨機代號**：格式如 `[USER-6vvit]`、`[DIR-evmae]`；同一個原文永遠對應同一個代號。亂數使用瀏覽器的 `crypto.getRandomValues`，字元集為小寫字母與數字 2–9（去掉易混淆的 `l`、`o`、`0`、`1`，共 32 個字元）。「代號長度」可設 4–50 字元（預設 5）；勾選「隨機長度」（預設勾選）時，每個代號的長度在 4 到「代號長度」之間隨機；不同設定各自保留一組代號，切回原設定時代號不變，舊代號仍可還原。可關閉類型前綴，也可一鍵重新產生。
- **批次處理檔案**：拖曳或點選上傳多個檔案，可預覽、單檔下載、全部下載、合併下載、合併複製；可選編碼（UTF-8、Big5、UTF-16 LE、Shift_JIS），文字檔輸出一律為 UTF-8，下載檔名也可去識別化；二進位檔會自動略過。
  - **Word / Excel（.docx、.docm、.xlsx、.xlsm）**：輸出同格式的檔案並保留排版，只改文字內容，圖片、樣式、巨集等其他內容原封不動；不需外部套件（用瀏覽器內建的解壓縮）
    - 同一段落（或儲存格）內被拆成不同格式的文字會串起來比對，例如路徑中間有一段粗體也能整段遮蔽；代號沿用被取代文字第一段的格式
    - Word 處理範圍：內文、表格、文字方塊、頁首頁尾、註腳、章節附註、註解、追蹤修訂刪除的文字、功能變數（例如超連結的路徑）、修訂與註解的作者、外部連結網址、文件屬性（作者、最後修改者、標題、公司等）
    - Excel 處理範圍：儲存格文字（含多種格式的文字）、公式的文字結果、註解與作者、圖形文字、外部連結網址、文件屬性
    - 預覽、合併下載、合併複製使用抽出的文字：Word 依段落輸出（頁首頁尾等另外標示），Excel 依工作表輸出成 Tab 分隔
    - 檔名代號、取代數、對照表與文字檔相同
- **對照表**：只列出目前「① 原始文字」與批次檔案用到的代號，隨輸入即時更新；可複製或下載 JSON，還原時可匯入。本機記住的代號不會顯示在表中，按「重新產生所有代號」才會清除。
- **設定與關鍵字區塊**：可摺疊（狀態會記住），標題旁顯示關鍵字數量。選項分成「個人資訊」「網路與帳密」「路徑」「代號與輸出」四組，滑鼠移到選項上可看詳細說明。「打包下載」會把關鍵字、Regex、白名單與下方所有勾選項目（含路徑取代方式、代號長度）存成 `anonymizer-settings.json`；「上傳匯入」可載入該檔（關鍵字、Regex、白名單和目前內容合併去重、勾選項目直接套用），也接受只含關鍵字的 JSON 或文字檔。另有「存為預設」「載入預設」（關鍵字、Regex、白名單與勾選項目一起存取）與「清空」（關鍵字、Regex 與白名單）；第一次開啟且尚無任何設定時，會自動套用預設。
- **可摺疊區塊**：批次處理檔案、③ 還原、設定與關鍵字、對照表預設都是收起，展開或收起的狀態會各自記住，下次開啟時依上次狀態還原。
- **版面順序**：① ② 輸入與結果 → 批次處理檔案 → ③ 還原 AI 回覆 → 設定與關鍵字 → 對照表。

## 範例

```
原文：C:\Users\WangXiaoMing\Documents\ACME\project-x\src\config.json
結果：C:\Users\[USER-6vvit]\Documents\[DIR-evmae]\[DIR-5q6ef]\src\config.json
```

## 注意事項

- 中文名詞是 AI 模型判斷，會有漏判與誤判（例如把「台北」這類常見地名也遮掉）；誤判的請加入白名單，漏判的請用關鍵字補上。模型以繁體中文正式文章訓練，log、路徑、中英混雜的文字準確度較低。
- Word / Excel 尚未處理的部分：Excel 的工作表名稱（改名會讓公式參照失效，只在預覽中遮蔽）、公式本身、頁首頁尾設定、樞紐分析快取、圖表內的文字、內嵌物件與圖片中的文字。舊版 .doc / .xls 與有密碼保護的檔案不支援。
- 電話號碼不偵測沒有分隔的市話（例如 `0223456789`），需要的話請用自訂 Regex。

- 對照表預設會存在瀏覽器的 localStorage，重新整理後仍可還原。其中包含原始路徑與帳密，不想留存請關閉「在本機瀏覽器記住對照表」，或在共用電腦上使用後清除瀏覽器資料。
- 規則式遮蔽無法保證涵蓋所有敏感資訊，貼給 AI 前請自行檢查結果。
- 設備設定檔目前尚未處理：`hostname`、`host-name`、網域名稱、`description`、`banner`、SNMP location / contact、Fortinet 的 SNMP community 名稱、AS 號碼、序號與授權。這些請用「額外關鍵字」自行加入。
- 設備密碼規則只收錄語法明確的寫法；明碼的 `password xxx`（例如 `line vty` 下未加密的密碼）、`snmp-server host` 的 community、`pre-shared-key`（Cisco IKEv2 / Juniper 之外的變形）等未處理，請自行檢查。
- 「目錄名稱可含空白」開啟時，若路徑中間夾雜一般句子，可能會多吃到文字，這時請關閉該選項。
